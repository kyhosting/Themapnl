## 🌟 Fitur Unggulan

- 🌌 **Nebula & Reviactyl Combo Style**: Desain modern dengan latar belakang Aurora Mesh dinamis dan palette Obsidian Space Void.
- 💎 **Ultra-Smooth Frosted Glass**: Efek blur mendalam (`backdrop-filter`) pada seluruh kartu, bar navigasi, modal, dan tabel.
- ⚡ **Reviactyl Power Action Buttons**: Tombol power (Start, Restart, Stop, Kill) dengan efek neon aura glow yang responsif.
- 📊 **Glowing Resource Meters**: Bar pemantauan CPU, RAM, Disk, dan Network dengan visual gradien modern.
- 🖥️ **Futuristic Terminal & Console**: Tampilan terminal console elegan dengan font JetBrains Mono dan glowing command prompt.
- 👑 **All-Menu Brand Protection**: Watermark dan identitas developer **Kicen x Thema Panel** terpasang rapi di seluruh navigasi, sub-navigasi, console, admin panel, dan footer.
- 🚀 **Zero-Build & Lightweight**: Tidak memerlukan build `yarn`/`node` yang membebani resource server/VPS. Pemasangan instan dalam hitungan detik.
- 📱 **Mobile & Desktop Fully Responsive**: Tampilan optimal di semua perangkat dari ponsel hingga layar ultrawide.

## 🚀 Cara Instalasi Publik (One-Line Command)

Jalankan perintah berikut di terminal server VPS Anda (sebagai root):

```bash
bash <(curl -s https://raw.githubusercontent.com/kyhosting/Themapnl/main/install.sh)
```

Setelah selesai, bersihkan cache browser Anda (**Ctrl + F5** di Windows/Linux atau **Cmd + Shift + R** di Mac).
